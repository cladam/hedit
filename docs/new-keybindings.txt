| Key       | Action                             | Description                                                          |
|---------- |----------------------------------- |----------------------------------------------------------------------|
| Ctrl-s    | Save, or Save-As on scratch        |                                                                      |
| Ctrl-o    | Open the "open file" prompt        |                                                                      |
| Ctrl-q    | Quit                               |                                                                      |
| Ctrl-c    | `copy`                             | Copy the current line to the clipboard.       				        |
| Ctrl-v    | `paste`                            | Paste clipboard contents at the cursor.       				        |
| Ctrl-z    | `undo`                             | Undo the last edit.                           				        |
| Ctrl-r    | `redo`                             | Redo the last undone edit.                                           |
| Ctrl-b    | back one char                      | Duplicate of ArrowLeft — nice for keeping hands on home row.         |
| Ctrl-f    | forward one char                   | Duplicate of ArrowRight.                                             |
| Ctrl-a    | start of line                      | New `MoveLineStart` action.                                          |
| Ctrl-e    | end of line                        | See conflicts below.                                                 |
| Ctrl-d    | delete char under cursor           | New `DeleteForward` action — hedit only has `DeleteBackward` today.  |
| Ctrl-k    | kill to end of line                | New `KillLine` action —  like `Copy`/`Paste`.                        |
| Ctrl-w    | kill previous word                 |                                                                      |
| Ctrl-y    | yank (paste killed text)           |                                                                      |
| Meta-o    | `new-buffer`                       | Push the current buffer to the ring and open a fresh scratch buffer. |
| Meta-n    | `next-buffer`                      | Cycle to the next buffer in the ring.                                |
| Meta-p    | `prev-buffer`                      | Cycle to the previous buffer in the ring.                            |
| Meta-w    | `close-buffer`                     | Close the active buffer, promoting the next one in the ring.         |
| Meta-f/b  | word forward/back                  | Needs Alt decoding                                                   |
| Meta-d    | kill word                          | Needs Alt decoding                                                   |
| Meta-l    | kill line                          | Needs Alt decoding                                                   |
| Meta-h    | `toggle-help`                      | Open/close the keybindings overlay.                                  |
| Arrow keys| Move the cursor.                   |                                                                      |
| Enter     | Split the line at the cursor.      |                                                                      |
| Backspace | Delete the char before the cursor. |                                                                      |
| Any char  | Insert at the cursor.              |                                                                      |
| Backspace | Delete the last typed char.        |                                                                      |
| Enter     | Submit (save-as / open the path).  |                                                                      |
| Esc       | Cancel, returning to the buffer.   |                                                                      |
